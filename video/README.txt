Сюда кладутся клипы для видео-фона: 1.mp4, 2.mp4, 3.mp4, 4.mp4
(список имён задаётся в config.js → BG_VIDEOS). Клипы идут по очереди, без звука.

Важно:
- Используй только ролики, на которые у тебя есть права (свои съёмки, лицензия или бесплатный сток
  вроде Pexels / Pixabay). Официальные ролики Red Bull защищены авторским правом.
- Делай клипы лёгкими: 10-15 секунд, 720p, до 5-8 МБ каждый, иначе фон будет грузиться долго.

Сжать ролик (нужен ffmpeg):
ffmpeg -i input.mp4 -an -t 12 -vf "scale=-2:720,fps=30" -c:v libx264 -crf 28 -preset slow -movflags +faststart 1.mp4
